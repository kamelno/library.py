# Library Management System

A comprehensive library management system built with Python OOP for managing books, members, and borrowing operations.

## Features

- ✓ Add and manage books
- ✓ Register library members
- ✓ Borrow and return books
- ✓ Track available book quantities
- ✓ View borrowed books by member
- ✓ View all books in library

## Requirements

- Python 3.8+

## Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/library-management-system.git
cd library-management-system

# Run the program
python library.py
```

## Usage

```bash
python library.py
```

Use the interactive menu to manage library operations.
